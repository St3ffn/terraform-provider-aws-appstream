## Retry and Timeout Behavior

This guide documents provider-level retry behavior and timeout settings for resources.

Notes:

- This is **in addition** to AWS SDK retries configured in the provider (`retry_mode`, `retry_max_attempts`,
  `retry_max_backoff`).
- `Retries = No` means there is no provider-specific retry loop for that operation.
- Each row describes one retry step. Operations can appear multiple times when they include multiple retry steps.
